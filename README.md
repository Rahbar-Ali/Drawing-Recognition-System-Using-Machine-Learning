# Drawing Recognition System Using Machine Learning 🎨🤖  

This project is a **Drawing Recognition System** that utilizes **Machine Learning** techniques to recognize hand-drawn sketches in real-time. The system applies **supervised learning (classification)** to analyze drawings and predict their categories.  

## 📌 Features  
✅ Real-time drawing recognition  
✅ Uses **K-Nearest Neighbors (KNN)** for classification  
✅ Data preprocessing: **scaling, cleaning, and normalization**  
✅ Custom chart interface for visualization and dataset expansion  
✅ Confusion matrix analysis for model performance evaluation  
✅ Fully interactive UI for user testing  

## 📂 Dataset  
The dataset contains **7,000+** user-drawn sketches collected using a custom-built interface. Data is categorized and processed using **feature extraction techniques** for optimal recognition accuracy.  

## ⚙️ Technologies Used  
- **Python** (NumPy, Pandas, OpenCV, Matplotlib)  
- **Machine Learning** (Scikit-learn)  
- **Deep Learning Models** (KNN)
